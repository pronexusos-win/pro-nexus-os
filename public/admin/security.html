🔑 รายการรอการอนุมัติคู่สองฝ่าย (Dual-Key Authorization Queue)

ธุรกรรมเสี่ยงสูงต้องใช้กุญแจ 2 ดอก (ผู้จัดการสาขา + CFO/คณะกรรมการตรวจสอบ) ป้องกันการใช้อำนาจเดี่ยว

COSO Control Enforced 🟢
รหัสคำขอ คำอธิบายธุรกรรม ระดับความเสี่ยง กุญแจดอกที่ 1 (ผู้ขอ) กุญแจดอกที่ 2 (ผู้อนุมัติ) สถานะ การจัดการ

⛓️ บัญชีประวัติแฮชแบบปิดผนึกลูกโซ่ (Tamper-Evident SHA-256 Audit Log)

ทุกการทำธุรกรรมถูกเข้ารหัสผูกโยงกับบล็อกก่อนหน้า หากมีการแก้ตัวเลขในฐานข้อมูลโดยตรง Hash จะแตกทันที

Immutable Ledger
โมดูล เลขอ้างอิงรายการ การกระทำ ผู้ปฏิบัติงาน SHA-256 Current Hash ความสมบูรณ์
